# empresasAmericaLatina
Este es el código mediante el que procesamos los datos brutos de las principales compañías lationamericanas.
El código está en R y modela los datos de los accionistas, las empresas, sus filiales, sus datos financieros y sus directivos.
El código incluye la capacidad de exportar el modelo de empresas conformado a una base de datos neo4j.
También se incluyen algunos archivos markdown para interrogar los datos y sacar tablas de resumen.
